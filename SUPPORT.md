# Поддержка

Разделы ниже — куда обращаться по вопросам `mock-services`.

- **Вопросы и дефекты мока** — GitHub Issues этого репозитория. Используйте
  шаблоны: «Дефект мока» (что сделали, что ожидали, что получили, `curl`-воспроизведение)
  и «Расхождение с протоколом» (ссылка на официальный раздел документации провайдера).
- **Уязвимости** — НЕ создавайте публичный issue. См. [`SECURITY.md`](SECURITY.md):
  приватный контакт мейнтейнеров или GitHub Security Advisories.
- **Документация** — карта документов и гайды «за 10 минут» начинаются с
  [`README.md`](README.md) и [`docs/overview.md`](docs/overview.md); опубликованный
  сайт — <https://axiiom.ru/mock-services/>.
- **Правила вклада** — [`CONTRIBUTING.md`](CONTRIBUTING.md); для ИИ-агентов —
  [`AGENTS.md`](AGENTS.md).
