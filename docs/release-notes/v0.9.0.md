# mock-services 0.9.0 — 2026-10-17

Релиз после наведения порядка в публичном репозитории: внутренние документы
выведены из продукта, добавлены community-файлы, исправлена подсказка в
`tbank-mock`. Протокольное поведение адаптеров не менялось.

## Что нового
- **Community-файлы**: `.github/pull_request_template.md` (единая схема отчёта PR),
  `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1) и `SUPPORT.md` — куда обращаться
  по вопросам, безопасности и документации. Community health GitHub: 62% → 87%.
- **Метаданные репозитория**: расширено описание, добавлены 20 topics, домашняя
  страница — https://axiiom.ru/mock-services/, включено авто-удаление смерженных
  веток.

## Исправления
- **`tbank-mock`**: подсказка HTTP 401 управляющей поверхности больше не ссылается
  на удалённый `docs/rfc/RFC-001-multi-tenant-sandboxes.md`, а ведёт на `SECURITY.md`,
  раздел «Изоляция песочниц». Закрыто регресс-тестом.

## Состав релиза
10 сервисов: `tbank-mock`, `kassa-mock` (Ferma), `yookassa-mock`, `atol-mock`,
`alfa-mock`, `sber-mock`, `vtb-mock`, `first-ofd-mock`, `kontur-ofd-mock`,
`taxcom-mock`; общее ядро, три compose-файла, Dockerfile, документация и OpenAPI.

  (`.gitattributes` `export-ignore`).
