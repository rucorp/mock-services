# mock-services 0.8.0 — 2026-10-16

Первый релиз после большой предрелизной волны: десятый сервис (Такском), финальные волны безопасности, публичная документация на домене компании и чистовые лицензионные шапки.

## Что нового
- **Такском — десятый мок-сервис** (`taxcom-mock`, :3109): read-only кабинет/ОФД по API v2 — `Login` + `Integrator-ID` → `Session-Token`, договоры/личные кабинеты, документы за 10 суток с курсором; честные коды ошибок и DX-подсказки.
- **Безопасность**: управляющие токены вне URL (заголовки/cookie), hosted-режим fail-closed по умолчанию, graceful shutdown всех сервисов, контейнерный харденинг всех compose-контуров.
- **Документация**: публичный сайт — https://axiiom.ru/mock-services/ (источник — этот репозиторий); гайды «интеграция за 10 минут» по всем 10 провайдерам, OpenAPI 3.1.
- **Лицензия**: шапки документов приведены к Apache-2.0, добавлен CI-страж; NOTICE и SPDX — без изменений.
- **CI/релиз**: полный гейт — для PR с кодом и тегов; релиз по тегу собирает образ (GHCR), архив-слепок и ноты.

## Состав релиза
10 сервисов: `tbank-mock`, `kassa-mock` (Ferma), `yookassa-mock`, `atol-mock`, `alfa-mock`, `sber-mock`, `vtb-mock`, `first-ofd-mock`, `kontur-ofd-mock`, `taxcom-mock`; общее ядро, три compose-файла, Dockerfile, документация и OpenAPI.
