# SZ probe-скрипты аудита alfa-mock — воспроизводимые доказательства к AUDIT-SZ-ALFA-2026-10-12

Скрипты — живые пробы независимого SZ-аудита альфы (серия PG-01…PG-11) и аддендума post-#55.
Запуск: `node docs/audit/tool-results/alfa-probes/<скрипт>.js` из корня репо (пути резолвятся от `__dirname`,
CWD не важен). Требования: Node >= 20; внешняя сеть не нужна. Безопасность: все listener'ы только
`127.0.0.1:0`, исходящие доставки — только на локальные фикстуры; `alfa-dns-toctou.js` подменяет DNS
исключительно внутри собственного процесса. Код репозитория скрипты не изменяют.
