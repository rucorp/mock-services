# Такском API — документы, частота опроса и границы интеграции

Срез API Help 2.17 от 30.12.2025. См. также [авторизацию/маршруты](01-api-auth-and-discovery.md).

## Новые фискальные документы

`GET https://<server>.taxcom.ru/API/v2/NewDocuments`, заголовок `Session-Token`; query `an` (необязательный номер договора), `id` (необязательный ID последнего полученного документа).

Метод возвращает только документы, принятые за последние 10 суток, не более 10 000 за вызов, сортирует по времени приёма Такскомом. Первый вызов без `id`; после него передавать ID последнего полученного документа до достижения хвоста; затем опрашивать **не чаще раза в минуту**. Если нет доступной ККТ — ошибка 3106; некорректный cursor — 2203. Типы включают открытие/закрытие смены, состояние расчётов, чек, чек коррекции, БСО и БСО коррекции.

Для детального состава документов и ответов применять схему `NewDocuments_Response` (Приложение №12) и остальные JSON-схемы приложений API Help v2.17; часть приложений не отображается в HTML. В версии 2.17 добавлены, среди прочего, ставки НДС 22%/22-122 в агрегатах смены. Точный публичный URL отдельного метода чтения одного ФД не удалось подтвердить по доступной HTML-части — не фиксировать непроверенный маршрут.

## Тестовый контур и доступ

Официальный API Help публикует отдельный host `api-tlk-ofd.taxcom.ru`, но не публичные логин, пароль, `Integrator-ID` или демонстрационные ККТ/чеки. Учётные данные предоставляются через Такском-Касса/техподдержку. Это API кабинета и чтения данных ОФД, а не стандартная «песочница оплаты картой».

## Что проверять для будущего адаптера/мока

- повторную авторизацию после TTL в пять минут и HTTP 401 для просроченного `Session-Token`;
- ошибки доступа, в т. ч. отсутствие видимых ККТ/кабинета;
- чтение потока новых документов с курсором и пределом десять суток/10 000 документов;
- состав NewDocuments и сортировку по времени приёма ОФД;
- отсутствие в публичном контракте операции записи чека и callback печати.

Для функционала отправки/возврата чека этого набора недостаточно: до решения о mock scope запросить у Такском отдельную спецификацию/продукт. Не имитировать методы Ferma или ATOL под именем Такском API.
