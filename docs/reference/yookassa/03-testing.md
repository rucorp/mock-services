# ЮKassa — тестовый режим и карты

Первичный источник: [официальная инструкция тестирования](https://yookassa.ru/developers/payment-acceptance/testing-and-going-live/testing). Срез 2026-10-11.

## Включение

Тестирование выполняется через demo-магазин и отдельные test shop ID/secret key из личного кабинета тестового магазина; API base остаётся `https://api.yookassa.ru/v3`. Ответ тестовых платежей помечен `test: true`. Тестовые ключи не являются ключами реального магазина.

Для всех тестовых карт указан срок действия позже текущей даты, CVC/CVV и 3DS-код допускают произвольные цифровые значения (точный UX 3DS зависит от выбранной карты). При проверке сохранения карты/автоплатежа использовать карту без 3DS.

## Успешные карты

| PAN | Платёжная система | 3DS |
|---|---|---|
| `5555 5555 5555 4477` | Mastercard | требуется |
| `5555 5555 5555 4444` | Mastercard | нет |
| `4793 1281 6164 4804` | Visa | требуется |
| `4111 1111 1111 1111` | Visa | нет |
| `4175 0010 0000 0017` | Visa Electron | нет |
