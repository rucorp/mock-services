## Что решить / сделать

1. Довести `kassa-mock` (контракт Ferma, `319c549e`, selftest 13/13,
   `mock-kassa-staging.lovii.ru`) до самостоятельного сервиса по
   архитектуре спеки §2: ядро «фискальный документ» + адаптер Ferma.
2. Протокол по официальной документации ОФД-провайдера (Ferma; следующий —
   АТОЛ Онлайн): фискализация, отчёты, возвраты, состояния чека
   (printed → callback → confirmed), тестовые ФД/ФП, вебхуки.
3. DX-слой: разбор ошибок фискализации (§6.2 спеки), сценарии (отказ ККТ,
   повтор после сбоя, таймаут callback), журнал доставки.
4. Selftest-набор + README «интеграция за 10 минут».

## Критерий приёмки

- Полный флоу 54-ФЗ Lovii (платёж → prepayment → чек → callback →
  confirmed, карточка T-038) гоняется против сервиса без правок кода.
- Незавершённые/сломанные сценарии воспроизводятся переключателем;
  selftest 🟢; ошибки с рекомендациями и ссылками на доку.
