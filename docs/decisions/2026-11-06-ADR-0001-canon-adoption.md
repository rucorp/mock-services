# ADR-0001: адаптация канона агентов «вариант C» в mock-services

- Статус: **accepted** (объём согласован владельцем 06.11.2026: docs-only, вариант 1)
- Дата: 06.11.2026
- Источник канона: репозиторий `bestdeejay-design/agents` (https://github.com/bestdeejay-design/agents):
  комплект «вариант C», утверждён владельцем 03.11.2026; оркестрация саб-агентов —
  ADR-0002 хаба от 06.11.2026 (`scripts/spawn-pack`, `skills/`, `preflight`, `guard-main`).
- Задача: rucorp/mock-services#168.

## Решение

Внедрить общие регламенты канона C в проект в объёме **docs-only**:

- [../AGENT_RULES.md](../AGENT_RULES.md) — регламент исполнителя;
- [../COORDINATOR_RULES.md](../COORDINATOR_RULES.md) — регламент координатора;
- таблица «Что читать перед работой» в корневом `AGENTS.md` §9 дополнена ссылками.

Нормы `AGENTS.md`, `CONTRIBUTING.md`, код, протоколы, CI и compose не меняются:
по `AGENTS.md` §0 при расхождении канона с файлами репозитория приоритет у файлов
репозитория.

## Отображение уровней канона C на механизмы проекта

| Канон C | mock-services |
|---|---|
| test | ветка поставки (`arena/*`, `fix/*`, `docs/*`) + зелёный `npm test` / CI на PR |
| staging | `main` после слияния PR (push в `main` — smoke-джоба Node) |
| production | теги `v*`: полная матрица Node 20/22/24 + docker, публикация образа GHCR (CI-политика 2026-10-15) |
| борд/Projects | не используется; источник статуса — labels в issues (набор заведён, сверен 06.11) |
| регресс | `npm test` (selftest'ы + `check:*`); предметные прогоны — по таблице `AGENTS.md` §2 |
| ревью | не-автором, вердикт на точный sha7 (`🔎 VERDICT #N — approve <sha7>`) |

## Ограничения (честный статус внедрения)

1. Механика хаба уровня 1.5+ (ADR-0002: `scripts/preflight`, `.githooks`, `guard-main`,
   `spawn-pack`, `schema/bus.json`, rulesets `dismiss stale approvals` / required
   reviewers, environments) **в проекте не установлена** — гейты держатся на дисциплине
   и ревью, что фиксируется в сводках до включения уровня 2 (по лестнице принуждения
   COORDINATOR_RULES хаба §12).
2. GitHub Projects-вид не создаётся; статус читается напрямую из labels/issues через `gh`.
3. Зависимостей нет и не появится (`AGENTS.md` §1): утилиты хаба при будущей раскатке
   потребуют отдельной задачи с решением владельца (bash/node, zero-dependencies).
4. Ссылки на хаб-репозиторий даны https-URL: это осознанное исключение из правила
   «только относительные ссылки» — правило действует для доков внутри репозитория
   (проверка `check:links` пропускает http(s)); публичная самодостаточность продуктовых
   доков не затронута.

## Откат

Правка docs-only: откат = реверс коммитов поставки; поведение сервисов не меняется.
